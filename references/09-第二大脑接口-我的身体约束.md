## 二、库里的引用格式（照抄，不发明）

### 2.1 证据引用索引（`知识/证据引用索引.md`）

分桶：A 营养 / B 脑科学 / C 康复体态 / D 健身 / E 感官学习。行格式：

```text
| A12 | 论断短语 | 作者 期刊 年;卷:页. PMID xxxxx | 【顶刊·系统综述】 | 用法判断（人群边界/能不能当因果） |
```

分层只有六个：【顶刊】【顶刊级（领域旗舰）】【专业期刊】【机制研究】【指南/共识】【证据弱·如实标注】。

### 2.2 分层 ↔ 证据等级映射

| 索引分层 | 写入笔记时的等级 |
|---|---|
| 顶刊 / 顶刊级 / 指南共识 | A |
| 专业期刊（领域旗舰） | B |
| 机制研究 / 证据弱 | C |

找不到文献的条目写【无充分文献】，并在「用法判断」里写必须怎么改口径——已有一例：C4-零（「体态矫正找回 1-3cm 身高」）。

### 2.3 域索引行格式（`知识/07…/域索引.md`）

```text
- ⭐ [[知识/07健康与生活-身体怎么养/训练与作息/文件名|别名]]（一句话：里面有什么、什么时候用）
```

### 2.4 碰撞日志格式（`_AI/碰撞日志.md`）

```text
## YYYY-MM-DD · 批次名
- **桥接概念（域×域）**：结论 + 挂接到哪个正本。
```

新知识入域前必须过这一道；建不了跨域联系就写「未碰撞」。

## 三、自我革新四循环（本技能怎么自己长）

| 循环 | 触发 | 动作 | 产物 |
|---|---|---|---|
| **L1 证据反哺** | 任何一次引用核验通过 | 把新文献追加到 `证据引用索引.md` 对应桶；新主题同时压缩进 `references/04-主题锚点文献.md` | 索引行 + 锚点行 |
| **L2 缺口扫描** | 用户说「革新/补证/查漏」，或距上次扫描超过 30 天 | `python scripts/vault_scan.py` → 逐行核 → 补证或降口径 | `知识/证据补强清单-<日期>.md` |
| **L3 迷思回收** | 读到库里「待清理迷思」「争议」「辟谣」条目 | 反向回填 `references/06-误用识别.md`，并补一条识别方法 | 误用库新增行 |
| **L4 约束回归** | 每次出建议前 | 跑三筛（年龄/发育/地贫）+ 查正本是否已有 | 输出里的「不适用于你」段 |

四循环的硬规矩：

- L1 只收「已核验」的文献，`NOT_FOUND` 的不进索引。
- L2 不自动改写正文——先出清单，人审后再动笔记。
- L3 不删旧的误用条，只追加时间戳与修正。
- L4 不许因为「文献这么说」绕过地贫/发育期红线；文献权重低于红线。

## 四、管道事实（踩过的坑，下次直接用）

1. **写库的权限**：bash 与 python 子进程直接写 `D:\SecondBrain_DSH` 会 `Permission denied`（受控文件夹保护）；`pwsh` 的 `Copy-Item`/`Set-Content` 和 `write` 工具可以写。
   标准姿势：脚本 `--out` 先写工作区 → `pwsh Copy-Item` 入库 → 删临时文件。
2. **不重跑 `second_brain_export.py`**（会重新生成已清理的会话记录类文件）。
3. **编码**：库内中文文件 UTF-8；PowerShell 用 `-Encoding utf8`，python 用 `encoding="utf-8"`，否则乱码。
4. **冲突裁决**：库内已有静论优先于外部新文献；要推翻已有条目，必须在碰撞日志里写出理由。

## 写库权限：vault 对 python 进程只读（2026-10-31 实测三次）

- 事实：`D:\SecondBrain_DSH` 整个目录对 python 进程 `open(...,'w')` 一律 `PermissionError`；DSH 文件工具与 PowerShell 可正常写。
- 规避三条：
  1. 脚本落盘全部带降级——`vault_scan.py --out-name` 写不进就落临时目录并打印搬运命令；`--mark` 写不进就把该行吐出来由外部追加。
  2. **中文路径不经命令行参数传给 python**（Git Bash 按 GBK 解码必乱码）：只传 ASCII 文件名（`--out-name`），目录由脚本内部拼。
  3. 索引行与报告正文用文件工具或 PowerShell 写回，不要让 python 直接改 vault。
