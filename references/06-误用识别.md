# 06 误用识别（人体与心理版的“八股陷阱”）

## 一、五个高频逻辑错误

### 1. 机制 ≠ 效果
“某物激活 AMPK / 提高 BDNF / 降低皮质醇”不等于“吃了变健康”。中间指标必须最终转化为硬结局。
正确写法：“在细胞与动物模型中观察到……，但尚无人体结局证据。”

### 2. 观察性 ≠ 因果
大队列里“喝咖啡的人活得久”可能是：喝咖啡的人收入更高、吸烟更少、病得更少。
判断工具：孟德尔随机化（MR）、负向对照、E-value、剂量-反应、停用后效应是否逆转。

### 3. 小鼠剂量 ≠ 人剂量
不换算就直接写“相当于人每天吃 X 克”是常见硬伤。换算与限制见 `01` 第五节。

### 4. 显著 ≠ 重要
n=200,000 的问卷可以做出 p<0.001 而效应量 d=0.01 的结果（手机使用与青少年幸福感的经典案例）。看效应量，不看星号。

### 5. 单研究 ≠ 定论
心理学可重复性危机已把大量“名实验”拉下神坛（启动效应、自我损耗、面部反馈假说、权力姿势）。规则：社会科学单篇 n<100 的行为实验默认当轶事。

## 二、神经科学与心理学的经典神话

| 说法 | 实际状态 |
|---|---|
| 左脑理性右脑感性 | 无支持；大多数任务全脑参与 |
| 人只用了 10% 大脑 | 错；全脑都在活动 |
| 学习风格（视觉/听觉/动觉型） | 无任何匹配式教学效果的证据 |
| 多元智力（8 种智力） | 测量学上未得到独立因子支持，教学应用无增量效度 |
| 莫扎特效应 | 效果来自唤醒与偏好，不来自音乐本身 |
| 阈下启动大幅改变行为 | 效应极小，原始研究多次重复失败 |
| 测谎仪能测谎言 | 测的是唤醒；假阳率高 |
| 记忆可以被“找回”并绝对可靠 | 记忆是可重构的；强暗示可制造虚假记忆 |
| 多巴胺 = 快乐分子 | 主要编码预测误差与“想要”，不是“喜欢” |
| 脑训练游戏能变聪明 | 只在训练任务上进步，远迁移证据弱 |
| 人类只有五种感官 | 远不止（平衡、本体、内脏、痛温等） |

## 三、健康新闻与营销的八个套路

1. **动物研究标题党**：标题写“彻底治愈”，正文小字写“小鼠实验”。
2. **相对风险放大**：把 1% → 0.8% 写成“降低 20%”。
3. **相关当因果**：把队列结果写成“XX 导致 YY”。
4. **替代终点当结局**：抗氧化、降炎症、延长端粒——都不等于活得更久。
5. **剂量偷换**：把高剂量提取物注射的结果，对应到日常口服食物。
6. **单一研究定论 + 专家背书**：无 meta、无重复，但有头衔。
7. **反向因果偷倒**：因为生病才多睡/多补，却被解读为“多睡/多补导致生病”。
8. **祖传/古老 = 安全有效**：传统使用与临床证据是两件事。

## 四、补剂评估的固定检查单

- 主结局是硬结局还是生物标志物？
- 人群是否营养充足（充足人群补了常常无效）？
- 剂量是否在生理范围？长期安全性数据有吗？
- 标示量是否与标签一致（第三方检测）？重金属/掺药风险？
- 是否有与药物的相互作用（华法林、SSRI、降压药）？
- 是否有大样本阴性试验被淡化（如 VITAL、D-Health）？

## 五、心理领域需要额外小心的三类

1. **量表代替诊断**：PHQ-9 高分不等于抑郁症，详见 `07`。
2. **疗法崇拜**：疗法名字（CBT、EMDR、催眠、正念）不等于疗效；要看具体障碍、对照条件、盲法、随访。
3. **创伤记忆与恢复记忆技术**：暗示性技术会制造虚假记忆，已有大量实验证据与法律案例。

## 六、AI/自媒体时代的特别风险

- **编造引用**：看起来真、DOI 解析不了。必须过 `scripts/ref_check.py`。
- **摘要幻觉**：模型“记得”某研究结论，实际那篇研究结论相反。必须打开摘要。
- **数字漂移**：n、p、效应量在转述中被篡改；只要写数字就回原文核。
- **预印本当同行评议**：引用时标 `[preprint]`，并写明“尚未同行评议”。

## 七、看到可疑说法时的处理流程

```text
1. 找原始文献（不是二手报道）
2. 看设计与结局（人类？硬结局？）
3. 看效应量与 CI（不是只看 p）
4. 找至少一篇独立重复或 meta
5. 查利益冲突与撤稿
6. 能用三句话向非专业人士说清楚吗？不能 = 你自己也没懂
```
