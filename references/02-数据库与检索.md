# 02 数据库与检索

检索顺序：**本地锚点（04）→ 指南/meta → 一手文献 → 预注册与灰色文献**。检索词用英文，结局词用 MeSH 术语。

## 二、权威二手来源（人话先从这里起步）

- **指南**：WHO、CDC、USPSTF、NICE（英国）、AHA/ACC（心血管）、ADA（糖尿病）、ACSM（运动）、ACOG（妇产）、中国营养学会/国家卫健委。
- **证据汇总**：Cochrane、UpToDate、BMJ Best Practice、Dynamed、USPSTF 推荐等级、GRADE 表格。
- **膳食参考摄入量**：IOM/NASEM DRI、中国 DRIs、EFSA。
- **补剂客观评测**：Examine.com（看它的引用原文，不只看结论）；NIH ODS Fact Sheets。
- 以上都是**二手**：正式写作时必须下到它引用的原始文献，并标出指南年份与版本。

## 三、PubMed / MEDLINE 检索语法

```text
("sleep deprivation"[MeSH] OR "sleep restriction"[tiab])
  AND ("cognitive performance"[tiab] OR "working memory"[tiab])
  AND (randomized controlled trial[pt] OR controlled clinical trial[pt])
  AND humans[MeSH] AND english[la]
  AND 2015:2026[dp]
```

常用标签：`[MeSH]` 主题词、`[tiab]` 标题摘要、`[pt]` 出版类型、`[dp]` 日期、`[la]` 语言、`[tw]` 全文本词。
过滤器直接用内置：`Randomized Controlled Trial`、`Systematic Review`、`Meta-Analysis`、`Humans`、`5 years`。

找高层证据的固定套路：

```text
# 先找 meta：
<topic>[tiab] AND (meta-analysis[pt] OR systematic review[pt])
# 再找最大的 RCT：
<topic>[tiab] AND randomized controlled trial[pt] AND (largest? ) → 按样本量人工挑
# 反向找：用某篇关键文献的 Cited by / Similar articles / 参考文献表
```

## 四、API（脚本直连，实测可用）

**Europe PMC**（检索 + 元数据 + 摘要；`resultType=core` 取全字段）：

```bash
curl -s "https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:10.1016/S0140-6736(12)61031-9&format=json&resultType=core"
curl -s "https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=TITLE:%22about%20sleep%27s%20role%20in%20memory%22&format=json"
# 全文 XML（开放获取）：
curl -s "https://www.ebi.ac.uk/europepmc/webservices/rest/PMC3645500/fullTextXML"
```

**Crossref**（DOI 权威注册库，拿卷期页与作者）：

```bash
curl -s "https://api.crossref.org/works/10.1016/S0140-6736(12)61031-9"
curl -s "https://api.crossref.org/works?query.bibliographic=sleep+duration+all-cause+mortality&rows=3"
```

**OpenAlex**（开放引文网络，查被引与撤稿）：

```bash
curl -s "https://api.openalex.org/works/doi:10.1016/S0140-6736(12)61031-9"
```

以上三个全部集成在 `scripts/ref_check.py` 里，写引用时不要手抄元数据。

## 五、中文库检索句式

- CNKI 专业检索：`SU=('睡眠限制' + '睡眠剥夺') * SU=('认知' + '工作记忆') * SU='随机对照'`
- 万方高级检索：`(主题:(睡眠 AND 认知)) AND (文献类型:期刊论文) AND (年份:2015-2026)`
- 中文检索容易漏同义词，一个概念至少列举 3 个说法（例：睡眠不足/睡眠剥夺/睡不够；压力/应激/心理压力）。
- 中文量表的信效度要看「中文版 + 中国人样本 + Cronbach α + 验证性因子分析」三件齐全，只看翻译不算。

## 六、检索记录（写论文/综述必做）

每轮检索落盘三行：数据库与日期、完整检索式、命中数。例：

```text
PubMed, 2026-10-31
("sleep restriction"[tiab]) AND ("working memory"[tiab]) AND randomized controlled trial[pt] → 87 hits
筛选：标题摘要 12 篇 → 全文 5 篇 → 纳入 3 篇
```

这是 PRISMA 流程图的最小版；没有它，「文献综述」就只是读后感。

## 七、找反证的固定动作（必做）

1. 在 PubMed 搜 `<结论> AND (fail* OR null OR "no effect" OR contradict*)`。
2. 看最近一篇大 meta 的 “Limitations” 与 “Heterogeneity”。
3. 查 Retraction Watch 与 PubMed 的撤稿标记。
4. 查 ClinicalTrials.gov 有没有同类试验**结果未发表**（发表偏倚的直接证据）。
5. 搜 Reddit/X 上专业人士的批评（只能当线索，必须回原文验证）。
