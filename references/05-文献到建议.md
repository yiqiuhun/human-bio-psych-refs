# 05 文献到建议（翻译层）

人体/心理研究最容易死在这一步：证据本身没错，但被译成了错误的建议。

## 零、出建议前的四行 Gate（任一为“是”就必须写人群声明，否则算未完成）

```text
[ ] 对象是 15 岁 / 发育期？（是 → 所有成人研究标“青少年外推”）
[ ] 涉及热量缺口或减重？（是 → 先过“发育期零缺口”纪律）
[ ] 涉及铁剂 / 维生素 C 与铁同服 / 红系指标？（是 → 先标地贫红线，建议先看医生）
[ ] 引用的关键证据人群与你差两个档以上（例如老年人→青少年、患者→健康人）？（是 → 降一级措词）
```

四项全“否”才可直接用常规口径；任一项为“是”而输出里没有对应声明 = 返工。

## 一、四象限定位（先分类，再写信）

轴：证据强度（强/弱）× 效应大小（大/小）

| | 效应大 | 效应小 |
|---|---|---|
| **证据强** | 立即做，优先级最高（例：吸烟者戒烟、每周 150 min 运动） | 可做，但别指望它改变命运（例：冥想 10 min、复合维生素以外的单一补剂） |
| **证据弱** | 经典陷阱：小鼠/机制研究被吹成神药（例：某提取物“抗衰老”） | 不值得花时间和钱（例：大多数“脑训练”App） |

写建议时先把这个方格画出来，不要把第二象限的东西写成第一象限。

## 二、从团体效应量到个人预期（四步换算）

1. **拿绝对风险，不拿相对风险**。RR 0.80 在 1% 基线风险 → 绝对下降 0.2 个百分点；NNT = 500。同一个 RR 在 20% 基线 → NNT = 25。
2. **乘两个折扣**：非依从性（真实世界依从率常 50–70%）与效应衰减（真实世界效应通常为 RCT 的 50–80%）。
3. **换算成单位时间**：把“风险降低 20%”换成“每 1000 人年少发生 X 例”或“你这类人 10 年内从 Y% 降到 Z%”。
4. **给出个体变异**：平均效应不代表你；用 2–4 周自测检验（见 `01` 末节）。

模板：

```text
该 meta 纳入 N 人、随访 M 年，干预组事件率 a%，对照组 b%，
绝对风险下降 (b−a) 个百分点，NNT ≈ 1/(b−a)。
对体型、BMI、年龄与你相近的人，预期收益应略小于此值。
```

## 三、剂量与执行参数（不是“多运动”而是多少）

建议必须可执行，含四个参数：**剂量、频率、时机、上限**。

| 维度 | 例 |
|---|---|
| 剂量 | 每周 150–300 min 中等强度；蛋白质 1.2–1.6 g/kg；纤维 25–29 g |
| 频率 | 抗阻 2–3 次/周，间隔 ≥48 h；间隔复习 1–3–7–14 天 |
| 时机 | 咖啡因距睡前 ≥ 8 h；高强度训练距睡前 ≥ 3 h；学习后当晚保证睡眠 |
| 上限 | 超过反而变差的位置：睡眠 > 9 h、酒精任何量、补剂超 UL |

没有这四行的“健康建议”是口号。

## 四、人群限定（必写）

每条建议后面补一个括号：适用于谁、不适用于谁。

- 默认人群：健康成年人（18–65，无慢病，非孕期）。
- 不适用的典型：青少年（需睡眠 ≥ 8–10 h）、孕期、心血管病患者（运动前评估）、正在服药者（相互作用）、进食障碍史（热量/体重话题）。

## 五、风险与不确定性语言（固定句式）

| 证据档位 | 推荐动词 | 示例 |
|---|---|---|
| 强 | “做”“建议” | “每周 150 min 中等强度运动降低全因死亡风险（高质量 meta，效应稳定）” |
| 有限 | “可以试”“很可能” | “可以试试固定起床时间；现有 RCT 样本小，效应中等” |
| 尚不成立 | “目前不支持”“不要指望” | “目前不支持靠某种补剂提升记忆力；证据仅限于动物与机制研究” |
| 有争议 | “双方证据并存，目前偏……” | “酒精与心血管的关系仍有争议，近期队列与大 GBD 分析结论相反” |

## 六、五个禁止动作

1. 用相对风险吓人或骗人（“降低 50%！”而不说基线）。
2. 把相关性写成因果（“熬夜导致……”应为“熬夜与……相关”）。
3. 用动物剂量支持人体推荐。
4. 把替代终点当结局（“降低了 CRP”≠“不生病”）。
5. 忽略基线风险与绝对收益，只讲“有效”。

## 七、输出结构（固定四段）

```text
1. 结论一句（带效应量与人群）
2. 证据有多硬（设计 + 一致性 + 局限）
3. 你能做什么（剂量/频率/时机/上限，一个动作就行）
4. 什么情况下不适用 + 何时该看医生
```

第 4 段不是免责声明，是医学常识的一部分；涉及药物、诊断、自伤风险、进食障碍、孕期用药时，必须写清楚就医路径。
