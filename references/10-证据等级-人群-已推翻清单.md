# 证据等级 · 人群口径 · 已推翻清单

`lit_find.py` 的表格里每个条目都带三样东西：**等级**、**人群·样本量**、**是否踩到被推翻主题**。
这一页是这三样的判读说明书。

---

## 一、等级怎么读（数字答设计，字母答能不能用）

| 等级 | 设计 | 能用它说什么 | 不能说什么 |
|---|---|---|---|
| **1a/A** | 系统综述、Meta 分析、指南 | 「这个方向上证据一致」 | 不能说个体一定受益；异质性大时只能给范围 |
| **1b/A** | 单个大样本 RCT（顶刊） | 「这个干预在这一人群里有因果效应」 | 不能外推到没入组的人群（年龄、病情、剂量） |
| **1b/B** | 单个 RCT（专业期刊） | 同上，但要写明样本量与随访长度 | 不能与 1a 等量齐观 |
| **2b/B** | 前瞻队列、观察性研究 | 「相关」——**不能推因果** | 不能写成「导致」；混杂和自报测量是硬伤 |
| **3b/B** | 病例对照 | 「这个暴露在病例中更常见」 | 不能给发生率；回忆偏倚大 |
| **4/C** | 横断面、问卷 | 「此刻这两件事同时存在」 | 不能谈时间顺序 |
| **5/C** | 叙述综述（无系统检索） | 当导读，当不了证据 | 不能引用其结论句当事实 |
| **6/C** | 机制研究、动物、体外 | 解释「为什么可能」 | 不能推效果，剂量不能直接换算到人 |

写句子的固定格式：**结论 + 效应量（含绝对风险） + 人群限定 + 等级**。
只写「研究发现显著」= 未完成；把 2b 写成因果 = 返工。

---

## 二、人群与样本量：为什么必须单列一栏

同一个问题，换个群体结论就翻面：

- **年龄**：儿童青少年与成人在药物代谢、睡眠结构、激素反应上都不同；15 岁发育期的结论不能从 40 岁人群平移。
- **性别**：女性在药物不良反应、体脂调节、疼痛阈值上的反应常与男性不同，很多老研究只收男性。
- **基线健康**：运动员 ≠ 久坐人群 ≠ 慢病患者；「健康成年人」小样本结论放到患病群体上是无效外推。
- **样本量**：N<30 的 RCT 效应量普遍虚高（小样本效应膨胀）；上千人的队列能把小效应测准，但也只能证明「相关」。

脚本只从标题/摘要自述里抽 `人群 · 年龄 · N`，**抽不到就写「未标明」——不猜**。
「未标明」不等于小样本，只等于「摘要没说，要打开全文看 Methods」。

## 三、已知被推翻或大幅缩水的主张（默认剔除）

`lit_find.py` 默认把落在这张表上的条目**删掉**（`--refuted flag` 改为标注并降权，`--refuted keep` 不管）。
这张表只做提示，不替你下判决——它是「先别急着用」的名单，不是「绝对错误」的名单。

| 主题 | 现状 | 处理建议 |
|---|---|---|
| 强势姿势（power posing）改变激素/风险偏好 | 多项重复失败，效应近零；原始研究统计方法受质疑 | 可当「自信姿态让人感觉更好」的弱建议，不可当激素证据 |
| 自我损耗 / 意志力像电池（ego depletion） | 多实验室预注册重复未获支持 | 别用它解释「我意志力用完了」 |
| 面部反馈假说（咬牙持笔更快乐） | 元分析校正后效应极小 | 只能当趣味知识 |
| 成长型思维干预（growth mindset） | 学业效应很小、异质性高，成本效益存疑 | 可以做，但别承诺提分 |
| 刻板印象威胁（stereotype threat） | 重复研究效应大幅缩水 | 不宜作为教学解释 |
| 内隐偏见训练 | 改变测量分数，不改变行为 | 不能当「培训过了就没偏见」 |
| 吃糖致儿童多动 | 多项 RCT 否定（期待效应） | 该管的是总热量与睡眠 |
| 味精致头痛 | 双盲试验未能重复 | 不必因「中餐馆综合征」忌口 |
| 夜间灯光致近视 | 后续队列削弱，遗传与户外时间更关键 | 护眼重点放户外光照 |
| 维生素 D 改善抑郁 | RCT 多为阴性（缺乏者补充除外） | 只对缺乏人群有意义 |
| 复合维生素改善认知 | 证据不一致、效应极小 | 不缺就别指望 |
| 排毒 / 清体 | 无生理机制、无临床证据 | 肝肾自己在做这件事 |

**扩展规则**：往表里加一条，必须同时能说出「哪篇重复研究/元分析否定了它」。
只凭印象加条目 = 把工具变成偏见放大器。

## 四、脚本层面的四道清洗（顺序固定）

1. **撤稿与更正**：标题以 Retracted/Retraction/Withdrawn/Expression of concern 开头，或出版类型标撤回 → 删。
2. **预印本**：未同行评议 → 默认删（`--include-preprints` 放开）。
3. **增刊会议摘要**：卷期带 `9S` / `Suppl` 或刊名含 Supplement → 默认删。它们有卷期页、长得像论文，最容易混进参考文献表。
4. **邻题噪声**：检索词在摘要里重合 <50%，或标题里重合 <1/3 → 删。判定为「没回答这个问题」。

保留边界：这四道只管「能不能进候选表」，**能不能引仍要过 `ref_check.py`**（看到 `VERIFIED` 才算数）。
